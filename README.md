## Featured case study

### ShinGiTai Global — Multilingual Corporate and Product Platform

A production Next.js website combining a holding-company presentation, dedicated product landing pages, locale-aware routing, multilingual technical SEO, controlled localization releases, Vercel deployment, and live production validation.

- Production languages: English, Norwegian, Polish, Japanese
- Production build: 351/351 static pages generated
- Japanese production smoke test: 9/9 key routes returned HTTP 200
- Case study: [read the full case study](case-studies/shingitai-global-multilingual-platform.md)
- Live website: `https://shingitaiglobal.com`
